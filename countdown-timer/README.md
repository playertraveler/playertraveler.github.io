# Countdown Timer

A simple web-based countdown timer that accepts minutes and seconds, then counts down to zero with Start, Stop, and Reset controls.

## Features

- Enter minutes and seconds
- Input validation with clear error handling
- Start from idle, pause while running, and resume from paused state
- Reset to the originally entered duration
- MM:SS display format with leading zeros
- Completion message when countdown reaches zero

## How to Run

1. Open the `countdown-timer` folder.
2. Open `index.html` in any modern web browser.
3. Enter a valid duration and use Start, Stop, and Reset.

## Technologies Used

- HTML5
- CSS3
- Vanilla JavaScript
